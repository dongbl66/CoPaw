## 🏗️ 核心决策与架构

### 技能管理系统

- **双源合并方案**（否决目录联接，采用运行时合并）：
  - `skills/` — copaw 内置技能（13 个）
  - `~/.agents/skills/` — 用户技能库（79 个）
- **skill.json 写入安全**：必须遵循 **读取→修改→验证→写入** 四步流程，避免 `json.dump` 数据丢失；copaw 动态管理该文件，不可依赖目录联接

### 客户端方案：三段式递进交付模式（2026-05-07 沉淀）

适用于复杂系统（制药/评审领域已验证），避免客户一次性投入过大：

| 阶段 | 目标 | 关键产出 |
|------|------|----------|
| **一、入口难题** | 模板化配置 + 数据采集 + AI 核心审核 | AI 自动模板配置（30-40 分钟替代传统数月）、自然语言审核规则配置 |
| **二、数据基石** | 数据底座 + 统计分析看板 | SPC、CPK 等统计看板 |
| **三、智能闭环** | 关键参数建模 + 事中预警 + 自动优化 | 错误语料库自愈机制 |

**产品匹配思路**：核心底座 + OCR + 分析引擎 + 信创硬件组合方案。

> **复用场景**：任何需要分阶段说服客户、降低初期门槛的 B 端复杂系统均可参考此递进模型。
