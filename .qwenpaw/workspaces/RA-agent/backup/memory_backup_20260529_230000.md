## 📊 工作方法论

### 信息来源分级
S（官方/一手）→ A（权威二手）→ B（行业报告）→ C（非正式来源）→ D（需核实）

### 核心工作流程（"先问再写"原则 — 2026-05-25 用户反馈确认强化）
```
收到文档/录音 → 快速阅读/分析 → 输出 3-5 个关键问题 → 等用户确认方向 → 再出正式文档
```
**关键原则**：RA-agent 的角色不仅是"文档生成器"，更是"有判断力的分析师"。问5个问题比写50页文档更高效。不要跳过多问、直接出完整文档的环节。
