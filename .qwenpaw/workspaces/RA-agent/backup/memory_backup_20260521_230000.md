## 🏗️ 核心决策与架构

### 技能管理系统

- **双源合并方案**（否决目录联接，采用运行时合并）：
  - `skills/` — copaw 内置技能（13 个）
  - `~/.agents/skills/` — 用户技能库（79 个）
- **skill.json 写入安全**：必须遵循 **读取→修改→验证→写入** 四步流程，避免 `json.dump` 数据丢失；copaw 动态管理该文件，不可依赖目录联接

### 客户端方案：三段式递进交付模式（2026-05-07 沉淀）

适用于复杂 B 端系统（制药/评审领域已验证），分阶段降低客户初期投入：

| 阶段 | 关键产出 |
|------|----------|
| **一、入口难题** | AI 自动模板配置（30-40 分钟替代传统数月）、自然语言审核规则配置 |
| **二、数据基石** | SPC、CPK 等统计分析看板 |
| **三、智能闭环** | 关键参数建模 + 事中预警 + 自动优化 + 错误语料库自愈 |

**产品组合**：核心底座 + OCR + 分析引擎 + 信创硬件。

> **复用场景**：需分阶段说服客户的任何复杂 B 端系统。
